# Python Games Collection (ПК, Android и Orange Pi Zero 3)

Коллекция 2D-игр на Python и Pygame с процедурной генерацией миров, графики и звука.

## 1. Cyber Platformer (`cyber_platformer` / `cyber_platformer_mb`)
Процедурный неоновый паркур-платформер с 4 биомами, крюком-кошкой и прокачкой модулей.

### Управление (ПК и Orange Pi)
* **A / D** или **Стрелки влево/вправо** — бег, скольжение по вертикальным стенам
* **W** или **Пробел (Space)** — прыжок, отскок от стены (*Wall-Jump*) и двойной прыжок (после покупки модуля)
* **Shift** или **X** — фазовый рывок (*Dash*), пробивает треснувшие стены с тайниками
* **E** или **C** — крюк-кошка (*Grappling Hook*), подтягивает к потолкам и уступам
* **S** или **Стрелка вниз** (в воздухе) — удар об пол сверху (*Ground Slam*), ломает треснувший пол
* **Z**, **J** или **Enter** — выстрел (Рельсотрон пробивает треснувшие стены)
* **Q** или **1–4** — переключение оружия
* **F** — открыть терминал апгрейдов (рядом с терминалом в конце уровня)
* **H** или **F1** — показать/скрыть шпаргалку по управлению

### Быстрый запуск на Orange Pi Zero 3 (DietPi)
```bash
sudo apt update && sudo apt install -y git python3-pygame xinit openbox
git clone https://github.com
xinit /usr/bin/python3 -O python-games/cyber_platformer/main.py
```
